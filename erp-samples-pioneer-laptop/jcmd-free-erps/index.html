Features
Everything you need to run your business
Built specifically for small Philippine businesses. Works offline-friendly, no setup required.
Dashboard
At-a-glance view of your key metrics — revenue, expenses, stock levels, and alerts.
Inventory
Track stock levels, set minimum thresholds, and get low stock alerts automatically.
Point of Sale
Quick order entry, cart management, and receipt generation for walk-in customers.
Expenses
Log all purchases and operating costs. Track what's paid, pending, or overdue.
Contacts
Manage suppliers and customers. Store contact info, notes, and purchase history.
Customizable
Built in plain HTML/CSS/JS. Easy to rebrand, recolor, and extend for your business.

How it works
Set up in minutes
No servers to manage. No monthly subscriptions. Just a free Supabase database and your browser.
1
Create a free Supabase account
Sign up at supabase.com — free tier gives you a full PostgreSQL database.
2
Run the setup SQL
Paste the included schema.sql into Supabase SQL Editor and click Run.
3
Add your credentials
Copy your Supabase URL and anon key into the js/supabase.js config file.
4
Open in browser
Open index.html with VS Code Live Server or deploy to GitHub Pages — done.
